# Food Delivery System

A backend API for an online food delivery platform built with FastAPI, SQLAlchemy, MySQL, and Alembic. It supports customers, restaurant owners, and delivery partners.

## Features

- JWT-based authentication and user roles
- Restaurant discovery and nearby restaurant search
- Restaurant categories and menu management
- Customer address management
- Shopping cart management
- Order creation and order history
- Coupon creation and discount application
- Online and Cash on Delivery (COD) payment workflows
- Restaurant-owner order acceptance, rejection, and status management
- Delivery partner profiles and availability
- Delivery assignment and OTP verification for pickup and delivery
- Delivery location updates
- Database migrations with Alembic
- Automated API tests with pytest
- Health and OpenAPI documentation endpoints

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- MySQL

## Installation

Open PowerShell in the project directory.

### 1. Create and activate the virtual environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 3. Configure environment variables

Copy the example configuration:

```powershell
Copy-Item .env.example .env
notepad .env
```

Set the database connection URL, JWT secret, and other required values in `.env`. Do not commit real passwords or secrets to source control.

### 4. Create the MySQL database

Create a database named `food_delivery_db` in MySQL, or use the database name configured in your `.env` file.

Ensure that the database URL points to the correct database and that the MySQL user has the required permissions.

### 5. Apply database migrations

```powershell
python -m alembic upgrade head
```

Check the current migration:

```powershell
python -m alembic current
```

## Run the Application

Start the development server:

```powershell
python -m uvicorn app.main:app --reload --reload-dir app
```

The API will be available at:

- **Swagger UI:** http://127.0.0.1:8000/docs
- **ReDoc:** http://127.0.0.1:8000/redoc
- **OpenAPI schema:** http://127.0.0.1:8000/openapi.json
- **Health check:** http://127.0.0.1:8000/health

The health endpoint returns the API health status.

## Main API Endpoints

| Feature | Endpoint |
|---|---|
| Register | `POST /auth/register` |
| Login | `POST /auth/login` |
| Current user | `GET /auth/me` |
| Restaurants | `GET /restaurants` |
| Nearby restaurants | `GET /restaurants/nearby` |
| Restaurant menu | `GET /restaurants/{restaurant_id}/items` |
| Cart | `GET /cart` |
| Add cart items | `POST /cart/items` |
| Addresses | `/addresses` |
| Coupons | `/coupons` |
| Customer orders | `/orders` |
| Restaurant-owner orders | `/owner/orders` |
| Update order status | `PATCH /owner/orders/{order_id}/status` |
| Delivery partner profile | `/delivery/partner/profile` |
| Partner deliveries | `/delivery/partner/deliveries` |
| Health check | `GET /health` |

Use Swagger UI to see request schemas, required roles, available methods, and response formats for each endpoint.

## Authentication

Protected endpoints use JWT authentication. Register or log in through the authentication endpoints, then use the **Authorize** control in Swagger UI to provide the access token.

Access to operations depends on the user's role, such as Customer, RestaurantOwner, DeliveryPartner, or Admin.

## Payments and Delivery

The checkout workflow supports Online and COD payment methods. Online payments use a mock-payment workflow rather than a real payment gateway.

Delivery completion uses OTP verification. Configure and test the delivery partner, order assignment, pickup verification, and delivery verification through Swagger UI.

## Testing

Run the automated tests:

```powershell
python -m pytest -v
```

The current API tests verify the health endpoint, OpenAPI schema, and key order and delivery route registrations.

## Database Migrations

Create a migration after changing database models:

```powershell
python -m alembic revision --autogenerate -m "describe your change"
```

Apply migrations:

```powershell
python -m alembic upgrade head
```

Review autogenerated migration files before applying them.

## Security Notes

- Keep `.env` out of source control.
- Use a strong, unique JWT secret.
- Do not commit database passwords, access tokens, or real customer data.
- Configure production-grade payment processing before handling real payments.
- Use a production ASGI server and appropriate HTTPS and database security settings for deployment.
